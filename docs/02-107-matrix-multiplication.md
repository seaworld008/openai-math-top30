# 02 · 矩阵乘法指数 ≤ 9/4

> 矩阵乘法指数从 2.37 猛降到 2.25——半个世纪来最大的一次飞跃，直接加速一切依赖矩阵运算的 AI 与科学计算。

## 🌱 小白版：这是什么问题？

两个很大的数字表格（矩阵）相乘，是 AI 训练、天气预报、搜索引擎背后最常用的计算。中学里学的"逐行乘逐列再求和"方法，对 n×n 的表格大约需要 n³ 次运算。1969 年，Strassen 发现了一个巧妙的"7 次乘法代替 8 次"的技巧，把指数降到约 2.81；之后五十多年，全世界数学家用越来越精妙的"激光法"一点点往下磨，到 2025 年才磨到约 2.3713——每次进步都只有小数点后第三、四位。这项成果宣称直接把指数打到 9/4 = 2.25，相当于一次跳过了几十年的渐进式改进。指数别看只小了 0.12：当 n 很大时，n^2.25 和 n^2.37 的差距是天文数字。

## 🎓 专业版：数学上到底说了什么？

记 ω 为方阵乘法的渐近指数：n×n 矩阵乘法可在 O(n^{ω+ε}) 次算术运算内完成（ε > 0 任意）。该手稿在 ℂ 上证明 ω ≤ 9/4，从而方阵乘法可在 O_ε(n^{9/4+ε}) 次算术运算内完成。在特征零的域上，对某个内维 n^a（a > 0.465），可实现 n^{2+o(1)} 的矩形乘法。进一步的界：在除去有限多个正特征之外的所有特征下 ω < 2.258；在每个固定域上 ω < 2.371054886006746。

## 🔬 这项成果做了什么？

该手稿在复数域上证明了 ω ≤ 9/4，给出 O_ε(n^{9/4+ε}) 次算术运算的方阵乘法。在特征零时，对某个 a > 0.465 的内维 n^a，允许 n^{2+o(1)} 的矩形乘法。进一步的平方界给出：在除去有限多个正特征之外 ω < 2.258，在每个固定域上 ω < 2.371054886006746。

## 🧗 难在哪？

1969 年 Strassen（ω ≤ log₂7 ≈ 2.807）打破了"n³ 最优"的信念；1990 年 Coppersmith–Winograd 用激光法得到 ω ≤ 2.3755；之后三十多年进展极其缓慢：Stothers / Vassilevska Williams（2010–12，约 2.3729）、Le Gall（2014，2.3728639）、Alman–Vassilevska Williams（2020，2.3728596）、Duan–Wu–Zhou（2023，2.371866，组合损失分析）、Vassilevska Williams–Xu–Xu–Zhou（2024，2.371552）、Alman–Duan–Vassilevska Williams–Xu–Xu–Zhou（2025，2.371339）。十几年总共才下降约 0.0015。从 2.371 直接跳到 2.25 是颠覆性的；ω = 2 的终极猜想（渐近秩猜想）仍未解决。

## 🚀 有什么用？

- **人工智能**：神经网络训练与推理的核心是矩阵乘法；指数下降意味着大模型训练成本的理论下界大幅降低。
- **科学计算**：有限元分析、天气预报、计算流体力学中的稠密线性代数求解。
- **计算机图形学与仿真**：实时渲染、物理引擎中的变换计算。
- **密码学与编码**：格密码等后量子方案中的矩阵运算加速。
- **量子计算模拟**：经典计算机模拟量子线路时的张量网络缩并，本质上是矩阵乘法。

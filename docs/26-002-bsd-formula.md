## 🌱 小白版：这是什么问题？

想象每条椭圆曲线是一座"数论大厦"。BSD 猜想说：大厦的"内部结构"（有多少个有理点）完全由它的"体检报告"（L 函数在 s=1 的表现）决定——报告越"异常"（零点阶数越高），"房间"（有理点）就越多。1960 年代初，Birch 和 Swinnerton-Dyer 用早期计算机算了大量例子，发现了这个规律。猜想还给出"首项公式"：把 L 函数的首项系数和曲线精细零件（Tate–Shafarevich 群大小、实周期、Tamagawa 数）用精确等式连起来。该手稿证明：只要曲线满足温和条件（某个素数的 Selmer 群余秩为 0 或 1），整个公式成立，包括最难的 Tate–Shafarevich 群有限性；配合手稿 006，覆盖了每条椭圆曲线"几乎全部"的二次扭转。

## 🎓 专业版：数学上到底说了什么？

设 E/ℚ 为椭圆曲线，L(E,s) 为其 Hasse–Weil L 函数，r = ord_{s=1} L(E,s) 为解析秩。BSD 猜想断言：(i) E(ℚ) 的 Mordell–Weil 秩等于 r；(ii) 首项公式 L^{(r)}(E,1)/r! = |Ш(E/ℚ)| · Reg(E/ℚ) · Ω_E · ∏_p c_p / |E(ℚ)_{tors}|²，其中 Ш 为 Tate–Shafarevich 群，Reg 为 Néron–Tate 高度配对的行列式（regulator），Ω_E 为实周期，c_p 为 Tamagawa 数。

## 🔬 这项成果做了什么？

该手稿证明了：对每条 ℚ 上的椭圆曲线，只要存在某个素数 q 使其全 q-幂 Selmer 群的余秩（corank）为 0 或 1，则该曲线的完整 BSD 首项公式成立，包括 Tate–Shafarevich 群的有限性。该 family 共 3 篇手稿。与结果 006（Goldfeld 猜想：二次扭转中解析秩 0 和 1 各占密度 1/2）结合，该手稿给出：每条 ℚ 上椭圆曲线的二次扭转中，一个密度为一的子集满足完整 BSD 公式。

## 🧗 难在哪？

BSD 猜想由 Bryan Birch 与 Peter Swinnerton-Dyer 于 1960 年代初（1965 年论文）基于计算机数值实验提出，是克雷数学研究所千禧年七大难题之一，悬赏 100 万美元。此前人类最好的结果是 Gross–Zagier（1986）与 Kolyvagin（1988–1990）：解析秩 0 或 1 蕴含代数秩等于解析秩且 Ш 有限；但包含所有精细常数的"完整首项公式"只在极特殊的曲线族上成立。该手稿把首项公式从特例推广到一个由 Selmer 条件定义的广泛曲线类，并借助 006 的密度结果把覆盖面推到"几乎全部二次扭转"。

## 🚀 有什么用？

- **密码学**：椭圆曲线密码（ECC，TLS、比特币都在用）的安全性依赖椭圆曲线有理点群的结构；BSD 公式把"难算的代数不变量"（如 Ш 的大小）与"可算的解析量"联系起来，为曲线选取与安全评估提供理论地基。
- **计算机科学**：BSD 是计算数论的核心猜想之一；首项公式的证明意味着一大类曲线的关键不变量原则上可被算法"读出"，推动算术几何的计算工具发展。
- **数学之美**：人类第一次对千禧年难题级别的猜想拿下"一大片"完整结果——解析与代数两座大陆之间架起了精确的桥。

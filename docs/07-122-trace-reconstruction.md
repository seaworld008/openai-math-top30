# 07 · 迹重构的定量界与统一解码器

> 给 DNA 测序式的"碎纸复原"问题画出第一条"不可能更少"的硬下界，并给出统一解码器的拟多项式上界。

## 🌱 小白版：这是什么问题？

想象有人把一张写满 0 和 1 的纸条随机撕掉一些字（每个字有固定概率被删掉），然后把剩下的碎片复印很多份交给你——你能拼出原纸条吗？这就是"迹重构"问题，它正是 DNA 测序的数学模型：测序仪读出的就是原 DNA 链随机丢失一些碱基后的"迹"。2004 年 Batu 等人提出这个问题后，二十年来大家只知道"大概需要指数级数量的碎片"，但没人知道最少需要多少。这项成果证明了：在固定删除概率下，任何方法都至少需要 n^{Ω(log log n)} 条迹——第一次排除了"多项式条迹就够"的可能性；同时给出了一个"统一解码器"，在已知的固定有理保留概率下达到拟多项式的样本量和运行时间。

## 🎓 专业版：数学上到底说了什么？

设删除信道以固定概率 δ ∈ (0,1) 独立删除二元串 x ∈ {0,1}ⁿ 的每一位，得到迹。问题：重构 x 需要多少条独立迹（样本复杂度）？该手稿证明：对每个固定的删除概率，重构任意长度 n 的二元串需要 n^{Ω(log log n)} 条独立迹，从而排除了多项式样本重构的可能性。一个统一解码器对已知的固定有理保留概率达到拟多项式的样本量与运行时间上界。当删除概率至多为 n^{−ε}（ε > 0 固定）时，样本与时间两界都成为关于输入和参数编码的多项式。

## 🧗 难在哪？

问题由 Batu–Kannan–Khanna–McGregor 于 2004 年系统提出（动机是计算生物学：从随机删除后的相似序列中寻找共同祖先序列）。上界方面：Holenstein 等（2008）给出 2^{Õ(√n)} 条迹；Nazarov–Peres（2017）、De 等（2017）改进到 2^{O(n^{1/3})}；Chase（2021）进一步推进到 exp(Õ(n^{1/5}))。下界方面长期只有平凡的 Ω(n)，后由 Holden–Lyons（2020）与 Chase（2021）改进到 Ω̃(n^{3/2})。"多项式条迹是否足够"这一核心问题悬置二十年。该成果的 n^{Ω(log log n)} 下界首次超越任何多项式，一举终结了这个猜测。

## 🚀 有什么用？

- **通信与编码**：删除信道是经典信道模型之一；样本复杂度的上下界直接指导纠删码设计与重传协议的效率评估。
- **生物信息学**：DNA 测序、基因组组装的理论极限——知道"最少需要多少条读段"才能保证重构，避免测序资源的浪费。
- **数据存储**：DNA 存储、分布式存储中应对随机丢失的编码方案设计。
- **计算机科学**：统一解码器的构造技术可迁移到其它噪声信道模型；深化了平均情形与最坏情形复杂度的理解。

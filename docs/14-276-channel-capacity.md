# 14 · 广义振幅阻尼信道的经典容量

## 🌱 小白版：这是什么问题？

光纤传信号会衰减，量子比特"飞行"久了也会漏能量（振幅阻尼），环境温度还会捣乱（热噪声）。一个量子信道每秒最多能传多少经典比特？这叫"经典容量"，是量子互联网的"网速上限"。1997–1998年，Holevo 等人给出了容量公式，但公式里有个"取极限"让人算不出来；2009年 Hastings 更证明：用纠缠来编码有时能突破单次使用的上限，所以这个极限省不掉。于是"振幅阻尼信道的真实容量到底是多少"悬了二十多年。该手稿宣称：对一切阻尼参数和温度参数，容量就是一个单变量优化问题的解，而且跟任何其他信道并用时容量可以直接相加。

## 🎓 专业版：数学上到底说了什么？

该手稿确定了一切量子比特广义振幅阻尼信道（一切阻尼与热参数）的无辅助经典容量：显式单变量优化给出容量，由独立双态信号系综与集体解码达到；Holevo 容量、最小输出熵与正则化经典容量在与任意有限维量子信道张量积时可加。

## 🔬 这项成果做了什么？

该手稿确定了每个量子比特广义振幅阻尼信道（包括一切阻尼与热参数）的无辅助经典容量。一个显式单变量优化给出容量，由独立双态信号系综与集体解码达到。Holevo 容量、最小输出熵与正则化经典容量在与任意有限维量子信道做张量积时可加。

## 🧗 难在哪？

经典容量的 HSW 定理（Holevo 1998；Schumacher–Westmoreland 1997）给出正则化公式；可加性猜想 2009年被 Hastings 证否（最小输出熵可超可加），故单次 Holevo 量是否等于真实容量长期未知。2021年对称广义振幅阻尼信道（n = 1/2）的精确容量被求出；2026年9月一篇 arXiv 论文对"有纯输出"的量子比特信道证明容量等于单次 Holevo 量，但明确把有限温度的广义振幅阻尼列为未解决。该手稿宣称把一切参数情形一次解决。

## 🚀 有什么用？

- 通信：振幅阻尼是光纤量子通信、量子存储器的主要噪声模型；容量公式直接给出量子互联网链路的理论速率上限与最优编码方案。
- 量子计算：噪声信道的精确刻画有助于量子纠错与错误缓解的设计。
- 计算机科学：量子信息论中"可加性"这一核心问题的实质进展。
